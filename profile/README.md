Aarexus is an independent parent brand for building software products, developer tools and original stories. We keep the portfolio small and the quality high: finish meaningful work, release it, then expand.

## Aarexus Software

Practical, maintainable software for individuals and organizations: developer tools and SDKs, end-user applications, and custom business solutions that automate workflows and cut repetitive work.

| Project | What it is | Status |
| --- | --- | --- |
| **AarxMaps** | Google Maps SDK for .NET with Core, Places and Routes modules. A refactor and polish of D3lg4doMaps. | Final stages before release |
| **Vectantic** | .NET library family for vector, semantic and mathematical capabilities, including local ONNX embedding workflows. | Coming up |
| **StocksWarden** | Portfolio and investment tracking application. | Coming up |

## Aarexus Studios

Original entertainment made with AI-assisted filmmaking tools. We start with short, song-based humorous stories, and the long-term goal is an original hip-hop sitcom. The stories, the humor and the characters come first. AI is how we produce them, not what we are about.

Studios is coming up.

## How we work

- **Build before expanding.** Finish and release what exists before starting something new.
- **Quality over project count.** A few polished products beat many unfinished ones.
- **Learn through release.** Ship, listen, improve.
